# Начните здесь — актуальная поставка

ТЗ 5.0 / пакет для первичного отбора кандидатов. Эта версия заменяет прежний ZIP с общим FAQ/заданиями.

1. Прочитать `TZ.md`. Окончательный сценарий: **вакансия → условия → явное согласие → PDF → ссылка на New work**.
2. Посмотреть `examples/recruitment.scenario.json` и `examples/materials/`. Полный текст владельца и оригинальный PDF включены.
3. Распределить работу по `docs/TEAM_ROLES.md` (рекомендация для четырёх исполнителей).
4. Использовать `src/` как основу: рекрутинговый workflow **уже реализован** в `workflow.py` и `recruitment_parser.py`. Прогнать тесты, проверить покрытие A01–B10.
5. Установить на Windows заказчика и провести **реальную приёмку** (R01–R17 по `docs/TEST_PROTOCOL.md`).

## Что реализовано в коде 0.2.0

- ✅ Telegram Business Bot API, long polling, проверка `can_reply`, fail closed при отзыве прав.
- ✅ Рекрутинговый workflow: машина состояний (NEW → CONDITIONS_SENT → CONSENT_RECORDED → PRESENTATION_SENT → INVITE_SENT / DECLINED / AWAITING_OWNER).
- ✅ Детерминированный parser (`recruitment_parser.py`): распознавание вакансии, явного согласия, отказа.
- ✅ Идемпотентная отправка: повторы не дублируют пакет, рестарт не повторяет PDF/ссылку.
- ✅ Строгая запись согласия: текст, UTC, chat ID, версия условий; согласие на старую версию не переносится.
- ✅ STOP / ручной режим / эскалация владельцу при неизвестном вопросе или правке сообщения согласия.
- ✅ SQLite на компанию, DPAPI-токен, NTFS-права, ProcessLock, backup/restore.
- ✅ 19 приёмочных тестов A01–B10 на моках + 23 офлайн-теста ядра.

## Локальная LLM

По ТЗ 5.0 LLM **необязательна** и условием сдачи не является. Сценарий работает на правилах и утверждённых текстах (`AI_MODE=faq`). Не тратить время на Ollama, если используются точные утверждённые тексты.

## Установка

Установка входит в задание этой же команде. **Не сдавать только исходники** вместо работающего экземпляра. Токен и доступ к Windows получают при установке, без передачи пароля Telegram.
