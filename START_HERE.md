# Начните здесь — актуальная поставка

ТЗ 5.0 / пакет для первичного отбора кандидатов. Эта версия заменяет прежний ZIP с общим FAQ/заданиями.

1. Прочитать TZ.md. Окончательный сценарий: вакансия → условия → согласие → PDF → ссылка на New work.
2. Посмотреть examples/recruitment.scenario.json и examples/materials. Полный текст владельца и оригинальный PDF включены.
3. Распределить работу по docs/TEAM_ROLES.md (рекомендация для четырёх исполнителей).
4. Использовать src как заготовку, доработать recruitment workflow, затем установить и провести реальную приёмку.

Рекрутинговый сценарий пока НЕ реализован в коде 0.2.0. Существующие тесты и старый аудит относятся к исходному ядру, не доказывают новый workflow. examples/recruitment.scenario.json не подключён к runtime.

README описывает базовую установку заготовки; требования TZ.md 5.0 имеют приоритет. Для нового сценария локальная LLM не обязательна; не тратить время на её установку, если используются точные утверждённые тексты.

Установка входит в задание этой же команде. Не сдавать только исходники вместо работающего экземпляра. Токен и доступ к Windows получают при установке, без передачи пароля Telegram.

Код для поиска пакета: TG-LOCAL-WIN-01. Это метка, не авторизация.
