# Лицензии и коммерческое использование

Исходный код ядра в этом пакете предоставлен заказчику для использования, изменения и дальнейшей коммерческой упаковки в пределах применимых условий предоставления сгенерированных материалов. Исключительность прав на сгенерированный код не обещается. Условия работ/прав команды фиксируются отдельно.

Встроенных сторонних Python runtime-зависимостей нет. Python распространяется по лицензии PSF; Ollama — отдельный компонент со своей лицензией (проверить конкретный релиз); qwen3:1.7b в официальной карточке Ollama указывает Apache 2.0. Бинарные программы и веса модели в ZIP не вложены. Перед распространением продукта команда сохраняет необходимые уведомления и сверяет лицензии фактически выбранных версий.
